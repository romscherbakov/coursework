# Лабораторная работа №3. Знакомство с RAID

## Цель работы

Познакомиться с технологией RAID и создать программный RAID-1 (зеркалирование) в Ubuntu Linux. Научиться проверять состояние массива, создавать файловую систему и монтировать её в каталог.

## Теоретические сведения

**RAID (Redundant Array of Independent Disks)** — технология объединения нескольких физических дисков в один логический массив для повышения производительности, надёжности или отказоустойчивости хранения данных.

В рамках работы рассматривается RAID-1 — зеркалирование. Данные записываются одновременно на два диска, поэтому содержимое одного диска дублируется на другом.

Если один диск выйдет из строя, данные останутся доступны на втором. Однако RAID-1 не заменяет резервное копирование: случайное удаление или повреждение файлов может отразиться на обоих дисках.

Основные уровни RAID:

- **RAID-0** — объединение дисков с распределением данных между ними. Повышает производительность, но не обеспечивает отказоустойчивость.
- **RAID-1** — зеркалирование данных. Обеспечивает отказоустойчивость за счёт дублирования информации.

Для создания программного RAID в Linux используется утилита `mdadm`.

## Требования

Перед началом работы необходимо добавить к виртуальной машине Ubuntu два дополнительных виртуальных жёстких диска:

- объём каждого диска — 1 ГБ;
- формат — VDI;
- тип выделения места — динамический;
- тип подключения — SATA.

Диски должны быть пустыми и не использоваться для хранения других данных.

**Внимание!** При создании RAID-массива содержимое выбранных дисков может быть перезаписано. Внимательно проверяйте имена устройств перед выполнением команд. Не используйте системный диск виртуальной машины.

## Задание

### Шаг 1. Установить утилиту mdadm

Обновите список доступных пакетов и установите `mdadm`:

```bash
sudo apt update
sudo apt install -y mdadm
```

**Пояснение:**

- `apt update` — обновляет список доступных пакетов;
- `apt install` — устанавливает программное обеспечение;
- `-y` — автоматически подтверждает установку;
- `mdadm` — утилита для создания и управления программными RAID-массивами в Linux.

### Шаг 2. Проверить подключённые диски

Выполните команду:

```bash
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
```

**Пояснение:**

Команда выводит список дисков и разделов с дополнительной информацией:

- `NAME` — имя устройства;
- `SIZE` — размер;
- `TYPE` — тип устройства (диск или раздел);
- `FSTYPE` — тип файловой системы;
- `MOUNTPOINTS` — точки монтирования.

Найдите два добавленных виртуальных диска объёмом 1 ГБ. В примере они называются `/dev/sdb` и `/dev/sdc`.

Имена устройств могут отличаться. Используйте те имена, которые отображаются в вашей виртуальной машине.

**Важно:** не перепутайте дополнительные диски с системным диском, на котором установлена Ubuntu.

### Шаг 3. Создать RAID-1

Выполните команду:

```bash
sudo mdadm --create --verbose /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
```

**Пояснение:**

- `--create` — создать RAID-массив;
- `--verbose` — выводить подробную информацию о выполнении команды;
- `/dev/md0` — имя создаваемого RAID-устройства;
- `--level=1` — уровень RAID-1 (зеркалирование);
- `--raid-devices=2` — количество дисков в массиве;
- `/dev/sdb /dev/sdc` — диски, которые будут использоваться в массиве.

Если система запросит подтверждение создания массива, введите `y` и нажмите Enter.

После выполнения команды в системе появится логическое устройство `/dev/md0`.

### Шаг 4. Проверить состояние RAID-массива

Выполните:

```bash
cat /proc/mdstat
```

**Пояснение:**

Файл `/proc/mdstat` содержит информацию о состоянии программных RAID-массивов.

В выводе можно увидеть:

- имя массива — `md0`;
- уровень RAID — `raid1`;
- количество активных дисков;
- состояние синхронизации данных.

Обозначение `[UU]` означает, что оба диска массива активны.

Если отображается процесс `resync`, дождитесь завершения синхронизации и повторите команду.

### Шаг 5. Создать файловую систему ext4

После создания массива необходимо подготовить его для хранения файлов.

Выполните:

```bash
sudo mkfs.ext4 /dev/md0
```

**Пояснение:**

- `mkfs` — создание файловой системы;
- `ext4` — тип файловой системы;
- `/dev/md0` — устройство, на котором создаётся файловая система.

После выполнения команды RAID-массив будет подготовлен для хранения файлов и каталогов.

**Важно:** форматирование удаляет прежнюю структуру данных на выбранном устройстве. Убедитесь, что указано именно `/dev/md0`, а не один из физических дисков.

### Шаг 6. Создать точку монтирования

Создайте каталог, в который будет подключён RAID-массив:

```bash
sudo mkdir /mnt/raid1
```

**Пояснение:**

Точка монтирования — каталог, через который пользователь получает доступ к содержимому файловой системы.

В этой работе для массива используется каталог `/mnt/raid1`.

### Шаг 7. Смонтировать RAID-массив

Выполните:

```bash
sudo mount /dev/md0 /mnt/raid1
```

**Пояснение:**

Команда `mount` подключает файловую систему устройства `/dev/md0` к каталогу `/mnt/raid1`.

После выполнения команды содержимое RAID-массива будет доступно через этот каталог.

Проверьте результат:

```bash
df -h /mnt/raid1
```

В выводе должна отображаться файловая система, смонтированная в `/mnt/raid1`.

### Шаг 8. Создать каталог внутри RAID-массива

Создайте каталог `temp`:

```bash
sudo mkdir /mnt/raid1/temp
```

Проверьте результат:

```bash
ls -la /mnt/raid1
```

**Пояснение:**

Каталог `temp` создаётся внутри смонтированного RAID-массива. Это позволяет убедиться, что файловая система доступна для работы.

### Шаг 9. Сохранить конфигурацию RAID-массива

Для того чтобы Linux мог автоматически обнаружить и собрать RAID-массив при загрузке системы, необходимо сохранить его конфигурацию.

Выполните:

```bash
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
```

Затем обновите начальный образ загрузки:

```bash
sudo update-initramfs -u
```

**Пояснение:**

- `mdadm --detail --scan` — получает информацию о существующих RAID-массивах;
- `tee -a` — добавляет полученную информацию в конец файла `/etc/mdadm/mdadm.conf`;
- `update-initramfs -u` — обновляет начальный образ загрузки Linux с учётом изменений.

Конфигурация сохраняется для последующего автоматического обнаружения и сборки массива при загрузке системы.

**Важно:** команды этого шага достаточно выполнить один раз. Повторное добавление той же конфигурации может привести к появлению дублирующихся записей в `mdadm.conf`.

Сохранение конфигурации RAID не настраивает автоматическое монтирование файловой системы в `/mnt/raid1` после перезагрузки. Для этого дополнительно используется файл `/etc/fstab`. Эта операция в рамках данной лабораторной работы не выполняется.

## Результат работы

В результате выполнения лабораторной работы должен быть создан программный RAID-1 из двух виртуальных дисков объёмом 1 ГБ каждый.

Массив должен быть:

- создан с помощью `mdadm`;
- отформатирован в файловую систему ext4;
- смонтирован в каталог `/mnt/raid1`;
- содержать каталог `temp`;
- иметь сохранённую конфигурацию для автоматической сборки при загрузке системы.

## Контрольные вопросы

1. Что такое RAID и для чего он используется?

   <details>
   <summary>Подсказка и ответ</summary>

   RAID — технология объединения нескольких дисков в логический массив для повышения производительности и/или отказоустойчивости хранения данных.

   </details>

2. Чем RAID-0 отличается от RAID-1?

   <details>
   <summary>Подсказка и ответ</summary>

   RAID-0 распределяет данные между дисками и повышает производительность, но не обеспечивает отказоустойчивость. RAID-1 дублирует данные на нескольких дисках.

   </details>

3. Для чего используется утилита `mdadm`?

   <details>
   <summary>Подсказка и ответ</summary>

   Для создания, настройки и управления программными RAID-массивами в Linux.

   </details>

4. Как проверить состояние RAID-массива?

   <details>
   <summary>Подсказка и ответ</summary>

   С помощью команды `cat /proc/mdstat`.

   </details>

5. Что такое точка монтирования?

   <details>
   <summary>Подсказка и ответ</summary>

   Каталог, через который пользователь получает доступ к содержимому смонтированной файловой системы.

   </details>

6. Для чего нужен файл `/etc/mdadm/mdadm.conf`?

   <details>
   <summary>Подсказка и ответ</summary>

   В нём хранится конфигурация RAID-массивов, необходимая для их обнаружения и сборки при загрузке системы.

   </details>

7. Сколько дисков может выйти из строя в RAID-1 из двух дисков без потери доступности данных?

   <details>
   <summary>Подсказка и ответ</summary>

   Один диск. Данные останутся доступны на исправном диске.

   </details>
