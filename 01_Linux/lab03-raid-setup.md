# Лабораторная работа №3. Знакомство с RAID

## Цель работы
Создать программный RAID-1 (зеркалирование) в Ubuntu Linux, отформатировать его и смонтировать.

## Теоретические сведения
RAID (Redundant Array of Independent Disks) — технология объединения нескольких физических дисков в логический массив для повышения надёжности и/или производительности. RAID-1 (зеркалирование) дублирует данные на всех дисках массива, обеспечивая отказоустойчивость: если один диск выйдет из строя, данные сохранятся на втором.

## Требования
⚠️ **Подготовка (делает преподаватель):** в VirtualBox к виртуальной машине Ubuntu добавить два виртуальных жёстких диска по 1 ГБ каждый (VDI, динамические). Диски должны быть подключены как **SATA**.

## Задание

### Шаг 1. Обновить список пакетов и установить `mdadm`

```bash
sudo apt update
sudo apt install -y mdadm
```

**Пояснение:** `mdadm` — утилита для управления программными RAID-массивами в Linux. Команда `apt update` обновляет список доступных пакетов, а `apt install` устанавливает нужную утилиту.

---

### Шаг 2. Посмотреть подключённые диски

```bash
lsblk
```

**Пояснение:** Команда показывает все диски и разделы. Новые диски обычно называются `sdb` и `sdc` (без цифр в конце — значит, без разделов). Запомните эти имена — они понадобятся на следующем шаге.

---

### Шаг 3. Создать RAID-1 (зеркало)

```bash
sudo mdadm --create --verbose /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
```

**Пояснение:** Создаётся массив `/dev/md0` уровня 1 (зеркалирование) из двух дисков. Флаг `--level=1` задаёт тип RAID, `--raid-devices=2` указывает количество дисков в массиве. При появлении запроса введите `y` и нажмите Enter.

---

### Шаг 4. Проверить статус массива

```bash
cat /proc/mdstat
```

**Пояснение:** Здесь видно текущее состояние массива и процесс его синхронизации. Вы увидите что-то вроде `[UU]` — это значит, что оба диска активны и работают.

---

### Шаг 5. Создать файловую систему ext4

```bash
sudo mkfs.ext4 /dev/md0
```

**Пояснение:** Команда `mkfs.ext4` форматирует массив в файловую систему ext4 — стандартную для Linux. При подтверждении введите `y`.

---

### Шаг 6. Создать точку монтирования

```bash
sudo mkdir /mnt/raid1
```

**Пояснение:** Точка монтирования — это папка, через которую мы будем «видеть» содержимое RAID. Без неё файловая система недоступна.

---

### Шаг 7. Смонтировать RAID

```bash
sudo mount /dev/md0 /mnt/raid1
```

**Пояснение:** Команда `mount` подключает устройство к файловой системе. Теперь содержимое RAID доступно по пути `/mnt/raid1`.

---

### Шаг 8. Создать директорию `temp` внутри RAID

```bash
sudo mkdir /mnt/raid1/temp
ls /mnt/raid1
```

**Пояснение:** Проверяем, что внутри смонтированного RAID появилась папка `temp`. Это подтверждает, что RAID работает корректно.

---

### Шаг 9. Сохранить конфигурацию массива

```bash
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
sudo update-initramfs -u
```

**Пояснение:** Первая команда сохраняет настройки RAID в конфигурационный файл, вторая — обновляет начальный образ загрузки. Благодаря этому массив будет автоматически собираться после перезагрузки.

---

## Результат
✅ Создан программный RAID-1, отформатирован в ext4, смонтирован в `/mnt/raid1`, внутри создана папка `temp`. Конфигурация сохранена для автоматической сборки при загрузке.
