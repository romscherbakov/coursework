# Лабораторная работа №1. Создание пользователя и настройка окружения

## Цель работы

Научиться создавать пользователей в Ubuntu Linux, управлять группами, предоставлять пользователям права администратора и настраивать историю команд с временными метками.

## Теоретические сведения

В Linux каждый пользователь имеет уникальный идентификатор (UID), основную и дополнительные группы (GID), домашний каталог и собственное окружение.

Информация о пользователях и группах хранится в системных файлах:

- `/etc/passwd` — сведения о пользователях;
- `/etc/group` — сведения о группах;
- `/etc/shadow` — информация о паролях пользователей.

Группа `sudo` позволяет выполнять команды с правами администратора.

Оболочка Bash поддерживает историю выполненных команд. Настройка временных меток позволяет видеть дату и время выполнения команд, что полезно для анализа работы и поиска ошибок.

## Задание

### Шаг 1. Создание пользователя `user`

Создайте нового пользователя:

```bash
sudo useradd -m user -s /bin/bash
```

**Пояснение:**

- `useradd` — команда создания нового пользователя;
- `-m` — создать домашний каталог пользователя `/home/user`;
- `-s /bin/bash` — назначить Bash в качестве командной оболочки пользователя.

Добавьте пользователя в группу `sudo`:

```bash
sudo usermod -aG sudo user
```

**Пояснение:** Группа `sudo` позволяет пользователю выполнять команды от имени администратора.

Параметры команды:

- `-a` — добавить пользователя в дополнительные группы, сохранив существующие;
- `-G` — указать список дополнительных групп.

Установите пароль для созданного пользователя:

```bash
sudo passwd user
```

Введите и подтвердите индивидуальный пароль пользователя.

**Пояснение:** Команда `passwd` предназначена для установки и изменения паролей пользователей.

Проверьте создание пользователя:

```bash
id user
getent passwd user
groups user
```

**Пояснение:**

- `id` — показывает UID, GID и группы пользователя;
- `getent passwd` — выводит информацию о пользователе из системной базы пользователей;
- `groups` — показывает группы, в которые входит пользователь.

**Дополнительные сведения:**

В Ubuntu также существует команда `adduser`:

```bash
sudo adduser user
```

В отличие от `useradd`, команда `adduser` является более удобным интерактивным инструментом: она самостоятельно создаёт домашний каталог, запрашивает пароль и предлагает заполнить дополнительные сведения о пользователе.

Таким образом:

- `useradd` — низкоуровневая команда с явным указанием параметров создания учётной записи;
- `adduser` — более удобный интерактивный инструмент, упрощающий создание пользователя.

В данной лабораторной работе используется `useradd` для знакомства с основными параметрами управления учётными записями.

---

### Шаг 2. Переключение на нового пользователя

Переключитесь на созданного пользователя:

```bash
su - user
```

**Пояснение:** Команда `su -` переключает на другого пользователя с загрузкой его login-окружения. Это означает, что будут установлены соответствующие переменные окружения и выполнен переход в домашний каталог пользователя.

Проверьте текущего пользователя и его окружение:

```bash
whoami
pwd
echo $HOME
id
```

**Пояснение:**

- `whoami` — показывает имя текущего пользователя;
- `pwd` — показывает текущий рабочий каталог;
- `echo $HOME` — выводит путь к домашнему каталогу;
- `id` — показывает идентификаторы пользователя и его группы.

Проверьте возможность выполнения команд с правами администратора:

```bash
sudo whoami
```

Введите пароль пользователя `user`.

Ожидаемый результат:

```text
root
```

**Пояснение:** Если команда вывела `root`, значит пользователь успешно получил возможность выполнять команды с административными правами.

Вернитесь к предыдущему пользователю:

```bash
exit
```

---

### Шаг 3. Настройка временных меток в истории команд

Снова переключитесь на пользователя `user`:

```bash
su - user
```

Добавьте настройку временных меток в файл конфигурации Bash:

```bash
echo 'export HISTTIMEFORMAT="%d.%m.%Y %H:%M:%S "' >> ~/.bashrc
```

Примените изменения:

```bash
source ~/.bashrc
```

**Пояснение:**

- `~` — домашний каталог текущего пользователя;
- `.bashrc` — файл настроек интерактивной оболочки Bash;
- `>>` — добавляет текст в конец файла, не удаляя существующее содержимое;
- `source` — выполняет команды из указанного файла в текущей оболочке;
- `export` — делает переменную окружения доступной для дочерних процессов.

Переменная `HISTTIMEFORMAT` задаёт формат отображения даты и времени в истории команд:

- `%d.%m.%Y` — дата в формате день.месяц.год;
- `%H:%M:%S` — время в формате часы:минуты:секунды.

---

### Шаг 4. Проверка настройки

Выполните несколько команд:

```bash
date
whoami
pwd
id
```

Просмотрите историю команд:

```bash
history
```

**Пояснение:** В истории должны отображаться команды с датой и временем их выполнения.

Обратите внимание: временные метки не восстанавливаются для старых записей истории, у которых ранее не сохранялась информация о времени выполнения.

## Контрольные вопросы

1. Чем отличается команда `adduser` от `useradd`?

   <details>
   <summary>Подсказка и ответ</summary>

   `useradd` — низкоуровневая команда с явным указанием параметров. `adduser` — интерактивная оболочка, упрощающая создание пользователя.

   </details>

2. Что такое UID и GID?

   <details>
   <summary>Подсказка и ответ</summary>

   UID — уникальный числовой идентификатор пользователя. GID — числовой идентификатор группы.

   </details>

3. Чем основная группа пользователя отличается от дополнительной?

   <details>
   <summary>Подсказка и ответ</summary>

   Основная группа назначается пользователю по умолчанию и используется, в частности, при создании файлов. Дополнительные группы предоставляют пользователю дополнительные права доступа.

   </details>

4. Для чего предназначена группа `sudo`?

   <details>
   <summary>Подсказка и ответ</summary>

   Позволяет пользователям выполнять команды с правами администратора через `sudo`.

   </details>

5. Что означает флаг `-aG` в команде `usermod`?

   <details>
   <summary>Подсказка и ответ</summary>

   `-a` — добавить пользователя в группы, не удаляя существующие дополнительные группы. `-G` — указать список дополнительных групп.

   </details>

6. Для чего предназначен файл `.bashrc`?

   <details>
   <summary>Подсказка и ответ</summary>

   Файл пользовательских настроек Bash. Содержит команды и параметры, выполняемые при запуске интерактивной оболочки.

   </details>

7. Чем отличаются операторы перенаправления `>` и `>>`?

   <details>
   <summary>Подсказка и ответ</summary>

   `>` — записывает данные в файл, перезаписывая его содержимое. `>>` — добавляет данные в конец файла, сохраняя существующее содержимое.

   </details>
