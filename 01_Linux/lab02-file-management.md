# Лабораторная работа №2. Навигация и работа с файлами

## Цель работы
Освоить базовые команды перемещения по файловой системе и управления файлами в Linux.

## Теоретические сведения
Файловая система Linux имеет иерархическую структуру. Для навигации по ней используются команды `pwd`, `cd`, `ls`. Для создания и управления файлами и каталогами применяются команды `mkdir`, `touch`, `cp`, `mv`, `cat`.

## Задание

### Шаг 1. Узнать текущий каталог

```bash
pwd
```

**Пояснение:** Команда `pwd` (print working directory) показывает, в какой папке вы сейчас находитесь.

---

### Шаг 2. Посмотреть содержимое каталога

```bash
ls
ls -la
```

**Пояснение:** Команда `ls` выводит список файлов. Ключ `-la` показывает скрытые файлы и подробную информацию (права, размер, дату).

---

### Шаг 3. Создать каталог и перейти в него

```bash
mkdir lab2
cd lab2
```

**Пояснение:** Команда `mkdir` создаёт папку, `cd` — переход в неё.

---

### Шаг 4. Создать файл и посмотреть его содержимое

```bash
touch file1.txt
echo "Hello, Ubuntu!" > file1.txt
cat file1.txt
```

**Пояснение:** Команда `touch` создаёт пустой файл. Команда `echo ... >` записывает текст в файл. `cat` выводит содержимое на экран.

---

### Шаг 5. Создать копию файла

```bash
cp file1.txt file1_copy.txt
ls
```

**Пояснение:** Команда `cp` копирует файл. Теперь в папке два файла.

---

### Шаг 6. Переименовать файл

```bash
mv file1_copy.txt file1_renamed.txt
ls
```

**Пояснение:** Команда `mv` используется и для перемещения, и для переименования файлов.

---

### Шаг 7. Вернуться в домашний каталог

```bash
cd ~
pwd
```

**Пояснение:** Символ `~` означает домашний каталог текущего пользователя.

---
