# 🔐 Сброс пароля пользователя Ubuntu Linux

Если пароль пользователя Ubuntu Linux забыт, его можно сбросить без переустановки операционной системы и потери данных.

Для этого воспользуемся режимом восстановления **Recovery Mode** через загрузчик GRUB.

## 1. Запуск Recovery Mode

1. Запустить виртуальную машину Ubuntu в VirtualBox.
2. Открыть меню загрузчика GRUB:
   - BIOS — удерживать `Shift` во время загрузки;
   - UEFI — несколько раз нажать `Esc` во время загрузки.
3. В меню GRUB выбрать:

   `Advanced options for Ubuntu`

4. Выбрать пункт с пометкой `(recovery mode)`.

## 2. Переход в консоль суперпользователя

В меню восстановления выбрать:

`root — Drop to root shell prompt`

Откроется командная строка с правами суперпользователя `root`.

## 3. Перемонтирование файловой системы

По умолчанию корневая файловая система может быть смонтирована в режиме только для чтения.

Перемонтировать её в режим записи:

```bash
mount -o remount,rw /
```

## 4. Определение имени пользователя

Посмотреть список домашних каталогов пользователей:

```bash
ls /home
```

Например, результат:

```text
student
user
```

Имя каталога обычно соответствует имени пользователя Linux.

## 5. Сброс пароля

Выполнить команду:

```bash
passwd student
```

Вместо `student` указать имя нужного пользователя.

Ввести новый пароль и повторить его для подтверждения.

> При вводе пароля символы на экране не отображаются — это нормальное поведение Linux.

При успешном выполнении появится сообщение:

```text
password updated successfully
```

## 6. Перезагрузка системы

Выполнить:

```bash
reboot
```

После перезагрузки войти в Ubuntu, используя новый пароль.

---

## Примечания

- Процедура не требует переустановки Ubuntu.
- Пользовательские файлы и настройки сохраняются.
- Для выполнения процедуры необходим доступ к меню GRUB.
- Если диск зашифрован или загрузчик GRUB защищён паролем, потребуется дополнительная процедура восстановления доступа.

## Результат

Пароль пользователя Ubuntu Linux успешно сброшен. Система готова к дальнейшей работе.
