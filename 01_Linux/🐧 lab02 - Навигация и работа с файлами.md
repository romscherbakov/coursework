# Лабораторная работа №2. Навигация и работа с файлами

## Цель работы

Освоить базовые команды навигации по файловой системе Linux, научиться создавать, просматривать, копировать, перемещать, переименовывать и удалять файлы и каталоги.

## Теоретические сведения

Файловая система Linux имеет иерархическую структуру. Её вершиной является корневой каталог `/`, от которого располагаются все остальные каталоги и файлы.

Для навигации по файловой системе используются команды `pwd`, `cd`, `ls`.

Для создания и управления файлами и каталогами применяются команды `mkdir`, `touch`, `cp`, `mv`, `cat`, `rm`, `rmdir`.

В Linux используются два основных типа путей:

- **Абсолютный путь** — полный путь к файлу или каталогу, начинающийся с `/`.
- **Относительный путь** — путь, указываемый относительно текущего рабочего каталога.

Полезные обозначения:

- `/` — корневой каталог файловой системы;
- `~` — домашний каталог текущего пользователя;
- `.` — текущий каталог;
- `..` — родительский каталог (на один уровень выше).

## Задание

### Шаг 1. Узнать текущий каталог

Выполните команду:

```bash
pwd
```

**Пояснение:** Команда `pwd` (print working directory) показывает полный путь к текущему рабочему каталогу.

### Шаг 2. Посмотреть содержимое каталога

Выполните команды:

```bash
ls
ls -l
ls -la
```

**Пояснение:** Команда `ls` выводит список файлов и каталогов.

Основные параметры:

- `-l` — подробный формат вывода: права доступа, владелец, группа, размер и дата изменения;
- `-a` — отображение всех файлов, включая скрытые (имена которых начинаются с точки).

Комбинация `-la` позволяет одновременно просмотреть скрытые файлы и подробную информацию о них.

### Шаг 3. Навигация по файловой системе

Перейдите в домашний каталог:

```bash
cd ~
pwd
```

Перейдите на один уровень выше:

```bash
cd ..
pwd
```

Вернитесь в домашний каталог:

```bash
cd ~
```

**Пояснение:** Команда `cd` (change directory) используется для перехода между каталогами.

- `cd ~` — переход в домашний каталог текущего пользователя;
- `cd ..` — переход в родительский каталог;
- `cd /` — переход в корневой каталог;
- `cd -` — возврат в предыдущий рабочий каталог.

### Шаг 4. Создать каталог и перейти в него

Создайте каталог `lab2` в домашнем каталоге пользователя:

```bash
mkdir lab2
```

Перейдите в созданный каталог:

```bash
cd lab2
pwd
```

**Пояснение:**

- `mkdir` (make directory) — создание каталога;
- `cd` — переход в указанный каталог;
- `pwd` — проверка текущего расположения.

В данном случае используется относительный путь `lab2`, так как команда выполняется из домашнего каталога пользователя.

Также можно перейти в этот каталог, указав абсолютный путь:

```bash
cd /home/user/lab2
```

### Шаг 5. Создать файл и записать в него текст

Создайте пустой файл:

```bash
touch file1.txt
```

Запишите в него текст:

```bash
echo "Hello, Ubuntu!" > file1.txt
```

Посмотрите содержимое файла:

```bash
cat file1.txt
```

**Пояснение:**

- `touch` — создание пустого файла (если файл уже существует, обновляет время его последнего изменения);
- `echo` — вывод текста;
- `>` — перенаправление вывода в файл с перезаписью его содержимого;
- `cat` — вывод содержимого файла на экран.

Добавьте ещё одну строку:

```bash
echo "Linux file system" >> file1.txt
```

Посмотрите содержимое файла повторно:

```bash
cat file1.txt
```

**Пояснение:** Оператор `>>` добавляет данные в конец файла, не удаляя ранее записанное содержимое.

### Шаг 6. Создать копию файла

Создайте копию файла:

```bash
cp file1.txt file1_copy.txt
```

Посмотрите содержимое каталога:

```bash
ls -l
```

Проверьте содержимое копии:

```bash
cat file1_copy.txt
```

**Пояснение:** Команда `cp` (copy) используется для копирования файлов и каталогов.

В результате в каталоге должны находиться два файла: `file1.txt` и `file1_copy.txt`.

### Шаг 7. Переименовать файл

Переименуйте созданную копию:

```bash
mv file1_copy.txt file1_renamed.txt
```

Проверьте результат:

```bash
ls -l
```

**Пояснение:** Команда `mv` (move) используется для перемещения и переименования файлов и каталогов.

Если указать новое имя в том же каталоге, файл будет переименован.

### Шаг 8. Создать и удалить каталог

Создайте дополнительный каталог:

```bash
mkdir backup
```

Проверьте содержимое:

```bash
ls -la
```

Переместите файл `file1_renamed.txt` в каталог `backup`:

```bash
mv file1_renamed.txt backup/
```

Посмотрите содержимое каталога `backup`:

```bash
ls backup
```

Удалите файл из каталога `backup`:

```bash
rm backup/file1_renamed.txt
```

Удалите пустой каталог:

```bash
rmdir backup
```

**Пояснение:**

- `rm` (remove) — удаление файлов;
- `rmdir` (remove directory) — удаление пустых каталогов;
- `backup/` — указание каталога, в который перемещается файл.

**Важно:** Команда `rm` удаляет файлы без перемещения в корзину. Перед её выполнением проверяйте имя и путь удаляемого файла.

### Шаг 9. Вернуться в домашний каталог

Выполните команду:

```bash
cd ~
pwd
```

**Пояснение:** Символ `~` обозначает домашний каталог текущего пользователя. Независимо от текущего расположения команда `cd ~` возвращает пользователя в его домашний каталог.

## Контрольные вопросы

1. Что показывает команда `pwd`?

   <details>
   <summary>Подсказка и ответ</summary>

   Показывает полный путь к текущему рабочему каталогу.

   </details>

2. Чем отличается `ls` от `ls -la`?

   <details>
   <summary>Подсказка и ответ</summary>

   `ls` показывает список файлов и каталогов. `ls -la` дополнительно отображает скрытые файлы и подробную информацию о них.

   </details>

3. Чем отличается абсолютный путь от относительного?

   <details>
   <summary>Подсказка и ответ</summary>

   Абсолютный путь начинается с `/` и указывает полный путь от корневого каталога. Относительный путь указывается относительно текущего каталога.

   </details>

4. Что означают символы `~`, `.` и `..` в Linux?

   <details>
   <summary>Подсказка и ответ</summary>

   `~` — домашний каталог пользователя; `.` — текущий каталог; `..` — родительский каталог.

   </details>

5. Как создать пустой файл?

   <details>
   <summary>Подсказка и ответ</summary>

   С помощью команды `touch имя_файла`.

   </details>

6. Чем отличаются операторы перенаправления `>` и `>>`?

   <details>
   <summary>Подсказка и ответ</summary>

   `>` записывает данные в файл с перезаписью содержимого. `>>` добавляет данные в конец файла.

   </details>

7. Какая команда используется для копирования файлов?

   <details>
   <summary>Подсказка и ответ</summary>

   `cp` (copy).

   </details>

8. Как переместить или переименовать файл?

   <details>
   <summary>Подсказка и ответ</summary>

   С помощью команды `mv` (move).

   </details>

9. Чем отличаются команды `rm` и `rmdir`?

   <details>
   <summary>Подсказка и ответ</summary>

   `rm` удаляет файлы, а `rmdir` удаляет пустые каталоги.

   </details>
