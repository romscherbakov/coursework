# Лабораторная работа № 4. Настройка SSH в Ubuntu Linux

## Цель работы

Настроить виртуальную машину Ubuntu Linux для удалённого управления по протоколу SSH и выполнить подключение к ней из основной операционной системы Windows.

## Исходные условия

- Основная операционная система — Windows.
- Гостевая операционная система — Ubuntu Linux, установленная в Oracle VirtualBox.
- В Ubuntu создан пользователь с правами `sudo`.
- В Windows доступен PowerShell.
- Виртуальная машина имеет доступ к локальной сети.

## Ожидаемый результат

В конце работы студент должен уметь:
- настроить сетевой адаптер виртуальной машины в режиме «Сетевой мост» (Bridged Adapter);
- определить IP-адрес Ubuntu;
- проверить наличие и установить OpenSSH Server;
- запустить службу SSH и включить её автоматический запуск;
- проверить прослушивание TCP-порта 22;
- проверить доступность порта из Windows;
- подключиться к Ubuntu по SSH и выполнить команды в удалённом терминале.

---

## Этап 1. Настройка сети VirtualBox

Для подключения из Windows настроим виртуальную машину так, чтобы она получила IP-адрес в той же локальной сети, что и основной компьютер.

### 1.1. Настройка сетевого адаптера

1. Завершите работу виртуальной машины Ubuntu.
2. В VirtualBox выберите виртуальную машину и откройте **Настройки → Сеть**.
3. На вкладке **Адаптер 1** установите флажок **Включить сетевой адаптер**.
4. В поле **Тип подключения** выберите **Сетевой мост (Bridged Adapter)**.
5. Нажмите **ОК** и запустите виртуальную машину.

> **Примечание.** В режиме сетевого моста виртуальная машина подключается к локальной сети как отдельное устройство и обычно получает IP-адрес от DHCP-сервера этой сети. Возможность работы Bridge зависит от настроек сети и драйвера физического адаптера.
> 
### 1.2. Определение IP-адреса Ubuntu

Войдите в Ubuntu и выполните:

```bash
ip -br a
```

Команда показывает сетевые интерфейсы и назначенные им IP-адреса.

Найдите активный сетевой интерфейс с IPv4-адресом. Не используйте адрес `127.0.0.1` — это адрес локальной петли (localhost).

Пример условного вывода:

```text
lo        UNKNOWN  127.0.0.1/8
enp0s3    UP       192.168.1.150/24
```

В этом примере IP-адрес Ubuntu — `192.168.1.150`.

**Запишите/запомните IP-адрес своей виртуальной машины:** 

> Фактическое имя интерфейса и IP-адрес могут отличаться. В дальнейших командах вместо `192.168.1.150` используйте адрес, полученный на своей виртуальной машине.

### 1.3. Проверка связи с Windows

Откройте PowerShell в Windows и выполните:

```powershell
ping 192.168.1.150
```

Замените адрес на IP-адрес своей Ubuntu.

Если получены ответы, базовая IP-связь работает. Если ответов нет, скажите об этом преподавателю.

## Этап 2. Проверка и установка SSH-сервера

Для входящих SSH-подключений в Ubuntu используется пакет `openssh-server`. Не путайте его с SSH-клиентом, который нужен для подключения к другим компьютерам.

### 2.1. Проверка наличия пакета

В терминале Ubuntu выполните:

```bash
dpkg -l openssh-server
```

Если пакет установлен, в начале строки его состояния будет `ii`.

Если пакет не установлен, переходите к следующему шагу.

### 2.2. Установка OpenSSH Server

Выполните:

```bash
sudo apt update
sudo apt install openssh-server -y
```

Назначение команд:

- `sudo` — выполнить команду с административными правами;
- `apt update` — обновить сведения о доступных пакетах;
- `apt install` — установить пакет;
- `-y` — автоматически подтвердить запрос на установку.

Если пакет уже был установлен, повторная установка не требуется.

### 2.3. Запуск службы и включение автозапуска

Выполните:

```bash
sudo systemctl enable --now ssh
```

Команда запускает службу `ssh` и настраивает её автоматический запуск при загрузке Ubuntu.

### 2.4. Проверка состояния службы

Выполните:

```bash
systemctl status ssh
```

Убедитесь, что в выводе присутствует состояние:

```text
Active: active (running)
```

Для выхода из просмотра статуса нажмите `q`.

## Этап 3. Проверка прослушивания порта 22

SSH использует TCP-порт 22 по умолчанию. Проверим, что служба действительно ожидает входящие подключения.

### 3.1. Проверка порта

Выполните в Ubuntu:

```bash
sudo ss -lntp | grep ':22'
```

Назначение параметров:

- `ss` — просмотр сетевых сокетов;
- `-l` — показать сокеты, ожидающие подключений;
- `-n` — показывать адреса и порты в числовом виде;
- `-t` — показать TCP-сокеты;
- `-p` — показать сведения о процессе.

Пример ожидаемого вывода:

```text
LISTEN 0 128 0.0.0.0:22 0.0.0.0:*
```

Возможен и другой корректный вариант, например с адресом `*` или `[::]:22`. Главное — увидеть состояние `LISTEN` для TCP-порта `22`.

Если команда ничего не вывела, проверьте состояние службы:

```bash
sudo systemctl status ssh
```

### 3.2. Проверка UFW

Проверьте состояние межсетевого экрана UFW:

```bash
sudo ufw status
```

- Если отображается `Status: inactive`, UFW не активен. Для этой лабораторной не нужно включать его специально.
- Если отображается `Status: active`, проверьте наличие разрешающего правила для SSH.

Если правила нет, добавьте его:

```bash
sudo ufw allow 22/tcp
```

Повторно проверьте правила:

```bash
sudo ufw status
```

> **Важно.** Состояние `LISTEN` означает, что программа ожидает подключения на порту. Это не гарантирует доступность порта с другого компьютера: на результат также влияют настройки сети и межсетевые экраны.

## Этап 4. Подключение к Ubuntu из Windows

На этом этапе проверим SSH не внутри виртуальной машины, а с основной операционной системы Windows.

### 4.1. Проверка доступности TCP-порта 22

Откройте PowerShell в Windows и выполните:

```powershell
Test-NetConnection 192.168.1.150 -Port 22
```

Замените IP-адрес на адрес своей Ubuntu.

Найдите в выводе параметр:

```text
TcpTestSucceeded : True
```

Значение `True` означает, что Windows смогла установить TCP-соединение с указанным адресом и портом.

Если указано `False`, проверьте:
- правильно ли указан IP-адрес Ubuntu;
- запущена ли служба `ssh`;
- прослушивается ли порт 22;
- разрешено ли входящее подключение правилами UFW;
- работает ли сетевой мост VirtualBox.

### 4.2. Подключение по SSH

В PowerShell выполните:

```powershell
ssh имя_пользователя@192.168.1.150
```

Например:

```powershell
ssh student@192.168.1.150
```

Замените `student` на имя пользователя, созданного в Ubuntu, а IP-адрес — на адрес своей виртуальной машины.

При первом подключении SSH может вывести предупреждение о том, что ключ узла ранее не встречался, и запросить подтверждение подлинности хоста. Если IP-адрес принадлежит вашей виртуальной машине, введите:

```text
yes
```

Затем введите пароль пользователя Ubuntu.

> При вводе пароля символы на экране не отображаются. Это нормальное поведение терминала. Введите пароль вслепую и нажмите Enter.

### 4.3. Проверка удалённой работы

После успешного подключения выполните в открывшемся SSH-сеансе:

```bash
whoami
hostname
pwd
```

Команды позволяют определить:
- `whoami` — имя текущего пользователя;
- `hostname` — имя компьютера;
- `pwd` — текущий рабочий каталог.

Если команды выполняются и отображают сведения об Ubuntu, удалённое подключение работает.

Для завершения SSH-сеанса выполните:

```bash
exit
```
