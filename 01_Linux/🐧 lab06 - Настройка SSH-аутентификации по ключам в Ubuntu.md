# HowTo. Генерация SSH-ключей и настройка автоматического входа в Ubuntu через MobaXterm

## Цель работы

Настроить подключение к гостевой операционной системе Ubuntu по протоколу SSH без необходимости вводить пароль пользователя `user` при каждом подключении.

Для аутентификации использовать пару SSH-ключей:
- **Приватный ключ** — хранится на компьютере студента (в MobaXterm).
- **Публичный ключ** — размещается в гостевой операционной системе Ubuntu.

## Шаг 1. Получение IP-адреса Ubuntu

1. Запустите виртуальную машину с Ubuntu.
2. Авторизуйтесь под пользователем `user`.
3. Откройте терминал и выполните команду:

```bash
hostname -I
```

4. Запишите IP-адрес виртуальной машины. Он понадобится для подключения из MobaXterm.

Например: `192.168.1.105`.

## Шаг 2. Генерация SSH-ключей в MobaXterm

1. Запустите MobaXterm.
2. Откройте локальный терминал (**Start local terminal**).
3. Выполните команду генерации ключей:

```bash
ssh-keygen -t ed25519 -C "user@ubuntu"
```

4. На вопрос о месте сохранения ключей нажмите `Enter`, чтобы использовать путь по умолчанию:

```text
~/.ssh/id_ed25519
```

5. На запрос пароля для ключа (**passphrase**) дважды нажмите `Enter`, оставив поле пустым.

Это необходимо для выполнения условия лабораторной работы — полностью автоматического входа без дополнительных запросов пароля.

После генерации будут созданы два файла:

| Файл | Назначение |
|---|---|
| `id_ed25519` | Приватный ключ. Не передавать другим пользователям! |
| `id_ed25519.pub` | Публичный ключ. Его необходимо скопировать на Ubuntu. |

Проверить наличие файлов можно командой:

```bash
ls -la ~/.ssh/
```

## Шаг 3. Подготовка Ubuntu к приёму публичного ключа

1. В локальном терминале MobaXterm выполните подключение к Ubuntu:

```bash
ssh user@192.168.1.105
```

Вместо `192.168.1.105` укажите IP-адрес своей виртуальной машины.

2. При первом подключении появится запрос подтверждения подлинности сервера. Введите:

```text
yes
```

3. Введите пароль пользователя `user` в Ubuntu.

4. После успешного подключения создайте каталог для SSH-ключей:

```bash
mkdir -p ~/.ssh
```

5. Установите необходимые права доступа:

```bash
chmod 700 ~/.ssh
```

6. Создайте файл для хранения публичных ключей:

```bash
touch ~/.ssh/authorized_keys
```

7. Установите права доступа к файлу:

```bash
chmod 600 ~/.ssh/authorized_keys
```

8. Завершите SSH-сеанс:

```bash
exit
```

## Шаг 4. Копирование публичного ключа на Ubuntu через SCP

Теперь необходимо передать публичный ключ с компьютера студента на виртуальную машину Ubuntu.

1. Убедитесь, что вы находитесь в локальном терминале MobaXterm, а не внутри SSH-сеанса Ubuntu.
2. Выполните команду:

```bash
scp ~/.ssh/id_ed25519.pub user@192.168.1.105:~/id_ed25519.pub
```

3. Введите пароль пользователя `user` в Ubuntu, если потребуется.

После выполнения команды публичный ключ будет скопирован в домашний каталог пользователя `user` на Ubuntu.

## Шаг 5. Добавление публичного ключа в authorized_keys

1. Подключитесь к Ubuntu:

```bash
ssh user@192.168.1.105
```

2. Добавьте скопированный публичный ключ в файл авторизованных ключей:

```bash
cat ~/id_ed25519.pub >> ~/.ssh/authorized_keys
```

3. Убедитесь, что права доступа установлены правильно:

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

4. Удалите временный файл публичного ключа:

```bash
rm ~/id_ed25519.pub
```

5. Завершите SSH-сеанс:

```bash
exit
```

## Шаг 6. Проверка подключения без пароля

В локальном терминале MobaXterm выполните:

```bash
ssh -i ~/.ssh/id_ed25519 user@192.168.1.105
```

Если всё настроено правильно, произойдёт автоматическое подключение к Ubuntu без запроса пароля пользователя `user`.

Для дополнительной проверки выполните:

```bash
whoami
```

Ожидаемый результат:

```text
user
```

## Шаг 7. Настройка сохранённого подключения в MobaXterm

Чтобы не вводить IP-адрес и параметры подключения вручную:

1. В MobaXterm нажмите **Session**.
2. Выберите тип подключения **SSH**.
3. В поле **Remote host** укажите IP-адрес Ubuntu.
4. Установите флажок **Specify username** и укажите:

```text
user
```

5. Перейдите в раздел **Advanced SSH settings**.
6. Установите флажок **Use private key**.
7. Укажите путь к приватному ключу `id_ed25519`, созданному на шаге 2.
8. Сохраните настройки подключения.

Теперь для подключения достаточно открыть сохранённую SSH-сессию в MobaXterm.

## Результат работы

В результате выполнения инструкции должно быть настроено SSH-подключение к Ubuntu под пользователем `user` с использованием аутентификации по публичному и приватному ключам.

При открытии сохранённой SSH-сессии MobaXterm подключается к виртуальной машине автоматически, без ввода пароля пользователя Ubuntu.
