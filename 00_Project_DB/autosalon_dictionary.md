# Справочник таблиц и атрибутов БД «Автосалон»

Справочник содержит названия таблиц и атрибутов на английском языке с русским переводом. Первичные и внешние ключи студенты определяют самостоятельно.

## 1. Модель автомобиля — `model`

| Название атрибута (англ.) | Название атрибута (рус.) |
|---|---|
| `model_id` | ID модели |
| `brand` | Марка автомобиля |
| `name` | Название модели |
| `release_year` | Год выпуска модели |

| `config_price` | Цена комплектации |

## Правила именования

1. Названия таблиц и атрибутов записываются на английском языке.
2. Используются строчные буквы.
3. Составные названия записываются в стиле `snake_case` — слова разделяются символом подчёркивания.
4. Первичные и внешние ключи студенты определяют самостоятельно.
5. Связи между таблицами устанавливаются с учётом бизнес-логики автосалона.
6. При создании таблиц необходимо определить подходящие типы данных и ограничения целостности.
