# Шпаргалка по SQL для практической работы «Автосалон»

Эта шпаргалка поможет выполнить практическую работу, даже если вы пока не очень хорошо знаете SQL.

В примерах используются таблицы базы данных `autosalon`. Перед выполнением запросов выберите базу:

```sql
USE autosalon;
```

## 1. Как посмотреть данные

Команда `SELECT` показывает записи из таблицы.

Посмотреть все модели:

```sql
SELECT * FROM model;
```

Посмотреть все автомобили:

```sql
SELECT * FROM car;
```

Посмотреть клиентов:

```sql
SELECT * FROM client;
```

Если нужно найти конкретную запись, используйте `WHERE`:

```sql
SELECT * FROM car
WHERE car_id = 3;
```

Здесь `3` — пример ID автомобиля. В своей базе используйте фактическое значение.

**Запомните:** перед изменением или удалением записи полезно сначала найти её через `SELECT`.

## 2. Как добавить данные — `INSERT`

Команда `INSERT INTO` добавляет новую запись в таблицу.

Пример добавления модели:

```sql
INSERT INTO model (name)
VALUES ('Toyota Camry');
```

- `model` — таблица, в которую добавляем запись.
- `name` — поле, в которое записываем значение.
- `'Toyota Camry'` — добавляемое значение.
- Текстовые значения записываются в одинарных кавычках.

Названия полей и их типы должны соответствовать структуре вашей таблицы.

### Как добавить автомобиль

```sql
INSERT INTO car (vin, config_id)
VALUES ('VIN-TRAINING-001', 1);
```

В этом примере `config_id = 1` — ID уже существующей комплектации. Если такой комплектации нет, MySQL не позволит добавить автомобиль.

**Важно:** если первичный ключ настроен как `AUTO_INCREMENT`, обычно его не нужно указывать в `INSERT`. MySQL присвоит его автоматически.

После добавления проверьте результат:

```sql
SELECT * FROM car;
```

## 3. Как изменить данные — `UPDATE`

Команда `UPDATE` изменяет существующие записи.

Общий вид:

```sql
UPDATE имя_таблицы
SET имя_поля = новое_значение
WHERE условие;
```

Например, изменить название модели с ID `1`:

```sql
UPDATE model
SET name = 'Toyota Corolla'
WHERE model_id = 1;
```

Изменить цену комплектации:

```sql
UPDATE config
SET price = 2500000
WHERE config_id = 1;
```

Изменить контакт клиента:

```sql
UPDATE client
SET phone = '+7-900-000-00-00'
WHERE client_id = 1;
```

Названия полей `name`, `price` и `phone` приведены как примеры. Используйте реальные названия из своей таблицы.

### Зачем нужен `WHERE`?

`WHERE` указывает, какую запись нужно изменить.

Без него запрос изменит значение **во всех строках таблицы**.

Перед изменением проверьте, какую запись вы выбрали:

```sql
SELECT * FROM model
WHERE model_id = 1;
```

После `UPDATE` выполните такой же `SELECT` и проверьте результат.

## 4. Как удалить данные — `DELETE`

Команда `DELETE` удаляет записи из таблицы.

Общий вид:

```sql
DELETE FROM имя_таблицы
WHERE условие;
```

Например, удалить автомобиль с ID `3`:

```sql
DELETE FROM car
WHERE car_id = 3;
```

Удалить модель с ID `2`:

```sql
DELETE FROM model
WHERE model_id = 2;
```

Перед удалением обязательно проверьте запись:

```sql
SELECT * FROM car
WHERE car_id = 3;
```

**Важно:** если на запись ссылаются другие таблицы, MySQL может запретить её удаление. Например, нельзя удалить автомобиль, который используется в продаже или бронировании, если ограничения внешнего ключа запрещают это.

Не выполняйте `DELETE` без `WHERE`: в таком случае будут удалены все записи таблицы.

## 5. Что такое первичный и внешний ключ

**Первичный ключ (Primary Key)** — поле, которое уникально определяет запись. Например, `car_id` определяет конкретный автомобиль.

**Внешний ключ (Foreign Key)** — поле, которое ссылается на запись в другой таблице. Например, `config_id` в таблице `car` указывает на комплектацию из таблицы `config`.

Пример связи:

- в таблице `config` существует комплектация с `config_id = 1`;
- в таблице `car` у автомобиля указано `config_id = 1`;
- если комплектации с таким ID нет, MySQL не позволит связать с ней автомобиль.

Поэтому при добавлении или изменении связанных записей нужно использовать существующие ID.

## 6. Что означают `RESTRICT` и `CASCADE`

Внешние ключи могут определять, что делать со связанными записями.

| Правило | Что означает |
|---|---|
| `ON DELETE RESTRICT` | Запрещает удалить запись, если на неё ссылаются другие записи. |
| `ON DELETE CASCADE` | При удалении родительской записи автоматически удаляет связанные записи. |
| `ON UPDATE CASCADE` | При изменении первичного ключа автоматически обновляет соответствующие внешние ключи. |
| `ON UPDATE NO ACTION` | Не позволяет изменить ключ, если это нарушит связь с другой таблицей. |

В MySQL InnoDB правила `RESTRICT` и `NO ACTION` при обычной проверке внешних ключей фактически работают одинаково.

### Как посмотреть настройки внешних ключей

Например, для таблицы `car`:

```sql
SHOW CREATE TABLE car;
```

В выводе найдите `FOREIGN KEY`, `ON DELETE` и `ON UPDATE`.

**Важно:** `CASCADE` не означает, что операция всегда разрешена. Она выполняется с учётом ограничений и других связей в базе.

## 7. Как проверить внешний ключ

Допустим, нужно назначить автомобилю несуществующую комплектацию:

```sql
UPDATE car
SET config_id = 999999
WHERE car_id = 3;
```

Перед выполнением убедитесь, что `car_id = 3` существует и выбранный автомобиль не используется в продаже или бронировании, если это важно для задания.

Если комплектации `999999` нет, MySQL должен отклонить изменение из-за ограничения внешнего ключа.

Если запрос завершился без ошибки, проверьте:
- существует ли автомобиль с указанным `car_id`;
- не изменили ли вы ноль строк;
- существует ли комплектация с указанным `config_id`.

## 8. Как читать сообщения MySQL

| Результат | Что это означает |
|---|---|
| Запрос выполнен успешно | Операция разрешена. |
| `1 row affected` | Изменена или удалена одна строка либо добавлена одна запись. |
| `0 rows affected` | Возможно, запись с указанным ID не найдена или значение уже было таким. |
| `Duplicate entry` | Нарушено ограничение уникальности, например повторяется уникальный VIN. |
| `Cannot add or update a child row` | Внешний ключ ссылается на несуществующую запись. |
| `Cannot delete or update a parent row` | Удаление или изменение запрещено из-за связанных записей. |

## 9. Короткий алгоритм работы

1. Посмотрите таблицу через `SELECT`.
2. Найдите нужную запись и её ID.
3. Выполните `INSERT`, `UPDATE` или `DELETE`.
4. Проверьте результат через `SELECT`.
5. Если MySQL выдал ошибку, прочитайте сообщение и проверьте связи между таблицами.
6. Если операция запрещена, не пытайтесь обходить ограничение: объясните, почему оно сработало.

**Главное правило:** в запросах `UPDATE` и `DELETE` внимательно проверяйте `WHERE`. Эта часть запроса определяет, какие именно записи будут изменены или удалены.
