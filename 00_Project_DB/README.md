# Практическая работа: Операции с данными в MySQL

## Цель работы

Научиться добавлять, изменять и удалять данные с помощью `INSERT`, `UPDATE`, `DELETE`, а также проверять работу `AUTO_INCREMENT` и внешних ключей.

## Подготовка к работе

Выберите один из вариантов:

**Вариант 1. Собственная база данных**

Используйте свою базу данных «Автосалон». Адаптируйте запросы под её структуру и ограничения.

**Вариант 2. Готовая база данных**

1. В OpenServer создайте базу, используя SQL-скрипт преподавателя.
2. Выберите базу данных:

   ```sql
   USE autosalon;
   ```

3. Добавьте учебные данные согласно заданиям.

## Общие требования

- Для каждого задания подготовьте отдельный SQL-запрос.
- Проверяйте результаты с помощью `SELECT`.
- Объясняйте причины возникающих ошибок.
- Не отключайте проверку внешних ключей.

**Важно:** поведение `UPDATE` и `DELETE` зависит от ограничений, заданных в вашей базе данных.
