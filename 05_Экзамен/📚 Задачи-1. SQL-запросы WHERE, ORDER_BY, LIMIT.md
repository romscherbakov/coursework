## Часть 1. Агрегатные функции и обработка данных

1. **Максимальная зарплата.** Найти максимальную сумму выплаты за всё время. Вывести результат в столбце `max_salary`. Использовать функцию `MAX()`.

2. **Средняя зарплата за март.** Найти среднюю сумму выплат за март 2026 года. Вывести результат в столбце `avg_salary`, округлив его до двух знаков после запятой. Использовать функции `AVG()` и `MONTH()`.

3. **Количество выплат за январь и февраль.** Подсчитать количество записей о выплатах за период с 1 января по 28 февраля 2026 года включительно. Вывести результат в столбце `payment_count`. Использовать функцию `COUNT()`.

4. **Сумма выплат 10-го числа.** Найти общую сумму всех выплат, совершённых 10-го числа любого месяца. Вывести результат в столбце `total_salary`. Использовать функции `SUM()` и `DAY()`.

5. **Замена слова в описаниях задач.** Вывести идентификатор и описание каждой задачи, заменив все вхождения подстроки `Починить` на `Исправить`. Исходные данные в таблице изменять нельзя. Использовать функцию `REPLACE()`.

6. **Количество уникальных тегов.** Подсчитать количество различных тегов, назначенных задачам с идентификаторами 10, 13 и 22. Один и тот же тег учитывать только один раз, даже если он назначен нескольким задачам. Использовать `COUNT(DISTINCT ...)` и таблицу `tags_tasks`.

7. **Процент выполненных задач.** Определить, какой процент задач, созданных в январе 2026 года, был выполнен. Задача считается выполненной, если значение `done` равно `1`. Вывести результат в столбце `completed_percent`, округлив его до двух знаков после запятой.

8. **Пять выплат, ближайших к 330.** Вывести 5 выплат, суммы которых ближе всего к 330. Показать ID выплаты, сумму, абсолютную разницу между суммой и 330, а также дату выплаты. Отсортировать по абсолютной разнице по возрастанию, а при равенстве разницы — по ID выплаты по убыванию.

9. **Среднее время исполнения задач.** Среднее время исполнения задач. Рассчитать среднюю продолжительность исполнения задач в минутах. Учитывать только задачи, у которых заполнены оба поля: started_at и end_at. Для расчёта продолжительности использовать TIMESTAMPDIFF(MINUTE, started_at, end_at), который возвращает разницу между временем окончания и временем начала в минутах.
Вывести результат в столбце avg_duration_minutes, округлив его до двух знаков после запятой.

## Часть 2. Объединение результатов запросов — `UNION`

10. **Общий список отделов и проектов.** Вывести названия всех отделов и проектов в одном списке. Результат должен содержать столбцы `name` и `category`, где категория обозначает `Отдел` или `Проект`. Объединить результаты двух запросов с помощью `UNION`.

Результат должен содержать столбцы name и category, где категория обозначает «Сотрудник» или «Проект». Использовать WHERE в обоих запросах и объединить результаты с помощью UNION.

Использовать два запроса с условиями `WHERE` и объединить результаты с помощью `UNION ALL`, чтобы сохранить все записи, даже если некоторые значения совпадают.

14. **Объединение задач по двум условиям.** Вывести задачи, которые выполнены (`done = 1`), и задачи, созданные в феврале 2026 года. Использовать `WHERE` в обоих запросах, объединить их с помощью `UNION ALL` и отсортировать итоговый список по идентификатору по возрастанию. ## Часть 3. Дополнительное задание
15. **Формирование описания сотрудника.** Вывести ID сотрудников и дополнительный столбец `description`, содержащий имя сотрудника и ID его отдела в формате `Сотрудник: [имя]; Отдел: [ID отдела]`. Для формирования описания использовать функцию `CONCAT()`

- `CONCAT()` объединяет фамилию, пробел, первую букву имени и точку.

## Пояснения

### Агрегатные функции

| Функция | Назначение |
|---|---|
| `COUNT()` | Подсчёт количества записей или значений |
| `MAX()` | Поиск максимального значения |
| `AVG()` | Вычисление среднего значения |
| `SUM()` | Вычисление суммы значений |

### Работа с датами и строками

| Функция | Назначение |
|---|---|
| `MONTH()` | Получение номера месяца из даты |
| `DAY()` | Получение дня месяца из даты |
| `REPLACE()` | Замена одной подстроки другой |
| `ROUND()` | Округление числового результата |

### Объединение запросов

- `UNION` объединяет результаты запросов и удаляет повторяющиеся строки.
- `UNION ALL` объединяет результаты запросов, сохраняя повторяющиеся строки.
- `WHERE` задаёт условия отбора записей внутри каждого запроса.
- `ORDER BY` позволяет сортировать общий результат объединения.

`UNION` и `UNION ALL` требуют, чтобы объединяемые запросы возвращали одинаковое количество столбцов в одинаковом порядке. Типы данных соответствующих столбцов должны быть совместимы.

При объединении запросов итоговую сортировку следует задавать после последнего `SELECT`, чтобы она применялась ко всему результату.
