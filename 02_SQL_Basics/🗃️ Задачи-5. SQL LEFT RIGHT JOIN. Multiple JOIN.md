## 🎯 Задачи для практики

### 🔄 Основные задачи на JOIN операции

#### 1. 📝 INNER JOIN с двумя таблицами

**Задача:** Вывести список всех задач с указанием имени сотрудника, которому поручено выполнение задачи.

#### 2. 👥 Multiple JOIN с одной таблицей

**Задача:** Вывести список задач с указанием имени сотрудника, который создал задачу, и имени сотрудника, который должен её выполнить.

#### 3. 🚀 Multiple JOIN с проектами и отделами

**Задача:** Вывести описание всех задач, название проекта, имя исполнителя и название отдела, в котором работает исполнитель.

#### 4. 🏷️ JOIN с Many-to-Many отношениями

**Задача:** Вывести список задач с указанием названий всех тегов, которые к ним привязаны.

#### 5. 📊 JOIN с агрегацией

**Задача:** Подсчитать количество задач, назначенных каждому сотруднику. Вывести имя сотрудника и количество задач.

#### 6. 🏆 JOIN с группировкой и сортировкой

**Задача:** Вывести названия отделов и количество выполненных задач сотрудниками каждого отдела. Отсортировать результат по убыванию количества задач.

#### 7. 📅 Multiple JOIN с фильтрацией по датам

**Задача:** Вывести список задач, созданных в феврале 2026 года, с указанием имени постановщика, исполнителя и названия проекта.

#### 8. 🎨 Multiple JOIN с фильтрацией по тегам

**Задача:** Вывести список проектов, в которых выполняются задачи с тегом «дизайн». Указать название проекта и количество таких задач.

#### 9. 💰 JOIN с агрегацией по отделам

**Задача:** Подсчитать общую сумму выплат зарплат сотрудникам каждого отдела. Вывести название отдела и общую сумму выплат.

#### 10. 🔍 Multiple JOIN с несколькими условиями

**Задача:** Вывести описание невыполненных задач, которые создали сотрудники отдела аккаунтинга, но выполняют сотрудники отдела разработки.

## 💡 Подсказки для решения

- 🎯 `INNER JOIN` возвращает только совпадающие строки из обеих таблиц.
- 🎯 `LEFT JOIN` сохраняет все строки из левой таблицы.
- 🎯 `RIGHT JOIN` сохраняет все строки из правой таблицы.
- 🔗 Для связи Many-to-Many через промежуточную таблицу нужны два `JOIN`.
- 👥 Одну таблицу можно подключать несколько раз, используя разные псевдонимы.
- 📊 При использовании агрегатных функций не забывайте про `GROUP BY`.
- 🔢 Используйте `COUNT(DISTINCT column)` для подсчёта уникальных значений.
- 🔍 Для поиска отсутствующих связанных записей используйте `IS NULL`.
- 🏆 Для фильтрации результатов группировки используйте `HAVING`.
- 📅 Для группировки по месяцам и годам можно использовать `YEAR()` и `MONTH()`.

## 🎯 Главное правило JOIN

- Таблица после `FROM` — левая (главная).
- Таблица после `JOIN` — правая (дополнительная).

### Позиционирование таблиц

```sql
FROM table1 LEFT JOIN table2
     ↑                 ↑
   ЛЕВАЯ             ПРАВАЯ
```

## 💡 Запомни

- `LEFT JOIN` = все строки из левой таблицы.
- `RIGHT JOIN` = все строки из правой таблицы.
- `INNER JOIN` = только совпадающие строки.

Порядок таблиц в запросе определяет, какая таблица будет левой, а какая правой!

## 🌟 Рекомендации по решению

1. Начинайте с определения таблиц, которые содержат необходимые данные.
2. Определите связи между таблицами по первичным и внешним ключам.
3. Начинайте построение запроса с простых `JOIN` и постепенно добавляйте остальные таблицы.
4. Используйте псевдонимы таблиц для удобства чтения запросов.
5. Проверяйте результат после каждого добавленного `JOIN`.
6. Обращайте внимание на `NULL` при использовании внешних соединений.
7. Не забывайте, что соединение таблиц Many-to-Many может приводить к дублированию строк.
