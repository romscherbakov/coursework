# 📚 Задачи-3. DISTINCT, GROUP BY и агрегатные функции

## Задания

1. **Общая сумма выплат.** Подсчитать общую сумму всех выплат из таблицы `salaries`.

2. **Средние суммы выплат по сотрудникам.** Вывести среднюю сумму выплат по каждому сотруднику за период до 1 марта 2026 года. Отсортировать результат по средней сумме выплат от большей к меньшей.

3. **Средние суммы выплат по месяцам.** Вывести среднюю сумму выплат для каждого месяца 2026 года.

4. **Месяцы с большой суммой выплат.** Вывести общую сумму выплат по каждому месяцу 2026 года. Оставить только месяцы, в которых общая сумма выплат больше или равна 2000.

5. **Количество тегов по задачам.** Подсчитать количество тегов для каждой задачи и вывести результат в порядке убывания количества тегов.

6. **Второй по популярности тег.** Вывести идентификатор второго по популярности тега. Популярность определяется количеством задач, в которых используется тег.

7. **Количество завершённых задач по сотрудникам.** Для каждого сотрудника, кроме сотрудников с идентификаторами `11` и `12`, вывести количество завершённых задач.

8. **Сумма выплат по месяцу и дню.** Вывести общую сумму выплат для каждой комбинации месяца и дня месяца.

9. **Уникальные суммы выплат.** Вывести все уникальные суммы выплат из таблицы `salaries` в порядке возрастания.

10. **Сотрудники, получавшие выплаты в разные месяцы.** Вывести уникальные идентификаторы сотрудников, получавших выплаты в январе или феврале 2026 года. Каждый сотрудник должен присутствовать в результате только один раз.

11. **Месяцы с большим количеством выплат.** Для каждого месяца 2026 года вывести количество выплат и их общую сумму. Оставить только месяцы, в которых было не менее 3 выплат, а общая сумма выплат превышает 1000. Отсортировать результат по общей сумме выплат по убыванию.

12. **Сотрудники с несколькими завершёнными задачами.** Вывести идентификаторы сотрудников и количество завершённых задач. Исключить сотрудников с идентификаторами `11` и `12`. Оставить только сотрудников, у которых не менее 3 завершённых задач. Отсортировать результат по количеству задач по убыванию.

13. **Популярные теги по задачам.** Для каждого тега вывести его идентификатор и количество задач, в которых он используется. Учитывать только теги, связанные как минимум с двумя задачами. Отсортировать результат по количеству задач по убыванию, а при равенстве — по идентификатору тега по возрастанию.

## Требования к выполнению

- Для каждого задания написать отдельный SQL-запрос.
- Использовать псевдонимы столбцов `AS`, если это необходимо для понятного вывода.
- Не изменять исходные данные в таблицах.
- При работе с датами учитывать указанные периоды.
- После выполнения каждого запроса проверить, соответствует ли результат условию задания.
