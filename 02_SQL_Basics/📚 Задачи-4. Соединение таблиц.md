# 📝 Задачи-4. Соединение таблиц, группировка и агрегатные функции.

### Задания

1. Вывести описание задач и имя сотрудника, который её выполняет.

2. Вывести список сотрудников с указанием наименования отдела, в котором работает каждый сотрудник.

3. Вывести список наименований тегов, связанных с задачей с `id = 9`.

4. Вывести список имён сотрудников, которые получали выплаты на сумму от 500.

5. Вывести список отделов с указанием количества работающих в каждом отделе сотрудников.

6. Вывести список наименований проектов с указанием количества незавершённых задач.

7. Вывести список сотрудников с указанием количества задач, которые они начали после 31 января.

8. Вывести список сотрудников с указанием общей суммы выплат за всё время.

9. Вывести список имён сотрудников, у которых есть незавершённые задачи, в которых они сами являются постановщиками и исполнителями.

10. Вывести ТОП-3 сотрудников, выполнивших наибольшее количество задач.

---

### Требования к выполнению

- Для решения задач использовать SQL-запросы.
- Результат каждого задания должен содержать только необходимые столбцы.
- При необходимости использовать `JOIN`, `GROUP BY`, `HAVING`, агрегатные функции и подзапросы.
- Запросы должны корректно обрабатывать отсутствие связанных записей.

### Результат работы

Предоставить SQL-запросы для всех 10 заданий и результаты их выполнения.
