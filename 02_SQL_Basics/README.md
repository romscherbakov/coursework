# Основы SQL

## Подготовка к работе

1. Запустите **OpenServer Panel**.
2. Убедитесь, что запущены службы **MySQL, Apache и PHP**.
3. Откройте phpMyAdmin через меню OpenServer Panel.
4. Импортируйте SQL-скрипт [`test3_database.sql`](./test3_database.sql), следуя указаниям преподавателя.
5. Убедитесь, что база данных и таблицы созданы.

После подготовки выполните задания практической работы, используя созданную базу данных.
