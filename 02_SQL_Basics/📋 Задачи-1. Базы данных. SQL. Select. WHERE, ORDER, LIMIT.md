# Практическая работа: Выборка данных из таблицы `tasks`

## Цель работы

Научиться составлять SQL-запросы с использованием `SELECT`, `WHERE`, `AND`, `OR`, `IN`, `LIKE`, `NOT LIKE`, `IS NULL`, `IS NOT NULL`, `ORDER BY`, `LIMIT` и `BETWEEN`.

## Структура таблицы `tasks`

| Поле | Описание |
|---|---|
| `id` | Идентификатор задачи |
| `project_id` | Идентификатор проекта |
| `creator_id` | Идентификатор постановщика |
| `worker_id` | Идентификатор исполнителя |
| `description` | Описание задачи |
| `done` | Статус выполнения: `1` — завершена, `0` — не завершена |
| `created_at` | Дата и время создания задачи |
| `started_at` | Дата и время начала выполнения |
| `end_at` | Дата и время завершения |


## Простые запросы

1. Вывести задачи, созданные в феврале 2026 года.
2. Вывести завершённые задачи, созданные в январе 2026 года. Отсортировать по дате создания по возрастанию.
3. Вывести задачи, которые уже начаты, но ещё не завершены. Отсортировать по дате начала по возрастанию.
4. Вывести задачи, в описании которых встречается слово «Бюджет».
5. Вывести 3 самые новые задачи. Отсортировать по дате создания по убыванию.
6. Вывести 2 самые старые задачи, которые ещё не были начаты. Отсортировать по дате создания по возрастанию.
7. Вывести задачи, назначенные сотрудникам с идентификаторами 8, 9 и 11. Отсортировать по идентификатору исполнителя по возрастанию.
8. Вывести все задачи, которые либо завершены, либо ещё не были начаты. Отсортировать по дате создания по убыванию.
9. Вывести задачи, у которых постановщик и исполнитель — один и тот же сотрудник.
10. Вывести задачи, созданные с 10 по 20 февраля 2026 года включительно.
11. Вывести задачи, в описании которых **не** встречается слово «Изменить».
12. Вывести задачи, которые уже начаты, но ещё не завершены.

## Комбинированные запросы

13. Вывести незавершённые задачи, в описании которых встречается слово «Изменить» или которые созданы сотрудником с id 12.
14. Вывести незавершённые задачи, назначенные сотрудникам с id 8 или 9. Отсортировать задачи по дате создания по убыванию.
15. Вывести незавершённые задачи, созданные в феврале 2026 года и уже начатые. Отсортировать задачи по дате начала по возрастанию.
16. Вывести завершённые задачи, созданные в феврале 2026 года, а также незавершённые задачи, назначенные сотруднику с id 8. Отсортировать по дате создания по убыванию.
17. Вывести незавершённые задачи, в описании которых встречается слово «Бюджет» или «ставки». Отсортировать по дате создания по убыванию.
18. Вывести задачи, созданные до 15 февраля 2026 года, которые уже начаты, но ещё не завершены. Отсортировать по дате начала по возрастанию.
19. Вывести следующие 5 задач после первых пяти в списке, отсортированном по дате создания от новых к старым.
20. Вывести не завершённые задачи, назначенные сотрудникам с идентификаторами 8, 9 или 12 и созданные с 1 по 20 февраля 2026 года включительно. Отсортировать по дате создания по убыванию и вывести не более 5 записей.

## Пояснение к сортировке

- **Отсортировать по дате по убыванию** — от нового к старому. Пример: март, февраль, январь; 3 -> 2 -> 1 
- **Отсортировать по дате по возрастанию** — от старого к новому. Пример: январь, февраль, март; 1 -> 2 -> 3 

## Требования к выполнению

- Для каждого задания написать отдельный SQL-запрос.
- Использовать `ASC` или `DESC` там, где требуется сортировка.
- Для проверки пустых значений использовать `IS NULL` и `IS NOT NULL`.
- В комбинированных запросах правильно группировать условия с помощью скобок.
- В запросах с `LIMIT` и `OFFSET` соблюдать порядок операторов: `ORDER BY`, затем `LIMIT`.

## Результат работы

Студент должен уметь выбирать данные из таблицы, фильтровать их по одному или нескольким условиям, сортировать результаты и ограничивать количество выводимых записей.
