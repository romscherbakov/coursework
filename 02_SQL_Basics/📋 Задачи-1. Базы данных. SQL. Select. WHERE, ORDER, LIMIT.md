# Практические задания по SQL: Операторы SELECT, WHERE и фильтрация данных

## Цель работы

Научиться составлять SQL-запросы с использованием `SELECT`, `WHERE`, `AND`, `OR`, `IN`, `LIKE`, `NOT LIKE`, `IS NULL`, `IS NOT NULL`, `ORDER BY`, `LIMIT` и `BETWEEN`.

## Структура таблицы `tasks`

| Поле          | Описание                                           |
| ------------- | -------------------------------------------------- |
| `id`          | Идентификатор задачи                               |
| `project_id`  | Идентификатор проекта                              |
| `creator_id`  | Идентификатор постановщика задачи                  |
| `worker_id`   | Идентификатор исполнителя задачи                   |
| `description` | Описание задачи                                    |
| `done`        | Статус задачи: `1` — завершена, `0` — не завершена |
| `created_at`  | Дата и время создания задачи                       |
| `started_at`  | Дата и время начала работы                         |
| `end_at`      | Дата и время завершения работы                     |

## Задания

1. Вывести все задачи, созданные в феврале 2020 года.
2. Вывести все завершённые задачи, созданные в январе 2020 года.
3. Вывести все задачи, которые были начаты, но ещё не завершены. Отсортировать результаты по дате начала работы в порядке возрастания.
4. Вывести все задачи, в описании которых содержится слово «Бюджет».
5. Вывести 3 самые новые задачи по дате создания.
6. Вывести 2 самые старые задачи, которые ещё не были начаты. Отсортировать их по дате создания в порядке возрастания.
7. Вывести все задачи, назначенные сотрудникам с идентификаторами `8`, `9` и `11`.
8. Вывести все задачи, которые либо завершены, либо ещё не были начаты.
9. Вывести все задачи, в которых постановщик и исполнитель — один и тот же сотрудник.
10. Вывести все задачи, в описании которых содержится слово «Изменить», либо задачи, созданные пользователем с `id = 12`, которые ещё не завершены.
11. Вывести все задачи, созданные в период с 10 по 20 февраля 2020 года включительно.
12. Вывести все задачи, в описании которых нет слова «Изменить».
13. Вывести все задачи, которые были начаты, но дата завершения которых не указана.
14. Вывести все незавершённые задачи, назначенные сотрудникам с `id = 8` или `id = 9`. Отсортировать результаты по дате создания от новых к старым.

## Требования к выполнению

1. Для каждого пункта написать отдельный SQL-запрос.
2. Сохранить все 14 запросов в одном SQL-файле.

## 💡 Подсказки по операторам

- **WHERE** - основная фильтрация
- **ORDER BY** - сортировка результатов  
- **LIMIT/OFFSET** - пагинация и ограничение вывода
- **LIKE** - поиск по шаблону
- **BETWEEN** - диапазон значений
- **IN/NOT IN** - принадлежность к множеству
- **AND/OR** - логические операторы
- **IS NULL** - проверка на пустое значение
